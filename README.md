## 📌 Project Overview

Cozy Coworking Space is a landing page recreated from a Figma design as part of my Full Stack Development training.

The project focuses on translating a visual design into a structured web page using HTML5 and CSS3.

## 💻 Technologies Used

- HTML5
- CSS3
- Git and GitHub

## ✨ Project Features

- Coworking space landing page layout
- Design implementation based on a Figma reference
- Navigation bar and introductory hero section
- Workspace features and service highlights
- Information cards with icons and descriptive content

## 🎯 Learning Objectives

- Practice converting Figma designs into HTML and CSS
- Improve page layout, typography, and visual styling
- Organize project files and assets
- Apply version control using Git and GitHub

## 👩‍💻 My Role

Recreated the provided Figma design and developed the HTML structure and CSS styling as part of my Full Stack Development training.
